01 / General

01 Què és Optigen? + ×

Optigen és una plataforma web que permet preparar scripts d'optimització personalitzats per al teu ordinador. Mitjançant un configurador guiat, pots seleccionar el teu sistema operatiu, el maquinari i les optimitzacions que vols incloure.

02 Com funciona la plataforma? + ×

Selecciona el teu sistema operatiu, indica els components del teu ordinador, tria un perfil d'optimització i decideix quins canvis vols incloure. Després de revisar la configuració, podràs generar i descarregar el teu script personalitzat.

02 / Compatibilitat i scripts

03 Quins sistemes operatius són compatibles? + ×

Optigen està dissenyat per a Windows i Ubuntu. Les optimitzacions i el tipus de script generat s'adapten al sistema operatiu seleccionat.

04 Quins tipus de scripts genera? + ×

Per a Windows genera scripts PowerShell amb extensió .ps1 i per a Ubuntu genera scripts Bash amb extensió .sh. Cada fitxer conté les optimitzacions que has seleccionat durant la configuració.

05 Com puc executar el script generat? + ×

Un cop descarregat, pots revisar el contingut del script abans d'executar-lo localment. A Windows pots fer servir PowerShell i a Ubuntu el terminal Bash. Es recomana fer una còpia de seguretat abans d'aplicar canvis al sistema.

03 / Configuració

06 Quins perfils d'optimització hi ha? + ×

Pots triar entre els perfils Rendiment, Equilibrat, Neteja, Gaming i Personalitzat. Cada perfil està orientat a diferents necessitats i formes d'utilitzar l'ordinador.

07 Puc seleccionar manualment les optimitzacions? + ×

Sí, pots activar o desactivar manualment les optimitzacions disponibles. Abans de generar el script podràs revisar tots els canvis seleccionats.

04 / Seguretat i control

08 Optigen modifica directament el meu ordinador? + ×

No. Optigen genera un script personalitzat que pots revisar abans d'executar-lo. Tu mantens el control sobre els canvis que apliques al teu ordinador.

09 Necessito instal·lar algun programa? + ×

No necessites instal·lar cap programa addicional per utilitzar el configurador web. Per executar els scripts faràs servir les eines corresponents del teu sistema operatiu, com PowerShell o Bash.

10 Què passa si tinc dubtes o problemes? + ×

Pots consultar la informació disponible a la plataforma per entendre millor el funcionament del configurador i les optimitzacions. Abans d'executar un script, revisa'n sempre els canvis i els possibles efectes.
