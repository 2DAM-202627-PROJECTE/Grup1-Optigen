Funcionalitats

Les eines per treure el màxim del teu equip

Una configuració adaptada al teu ordinador, amb el control de cada canvi a les teves mans.

01

Configuració guiada

Un procés pas a pas que t'ajuda a preparar la configuració del teu ordinador sense haver de tenir coneixements tècnics avançats.

02

Adaptació al teu maquinari

Indica els components del teu equip, com el processador i la targeta gràfica, per preparar una configuració adaptada a les seves característiques.

03

Perfils d'optimització

Tria entre diferents perfils segons les teves necessitats: Rendiment, Equilibrat, Neteja, Gaming o Personalitzat.

04

Control dels canvis

Selecciona manualment les optimitzacions que vols incloure i revisa-les abans de generar el teu script.

05

Scripts personalitzats

Genera un script adaptat a la configuració seleccionada, preparat per descarregar i executar localment al teu ordinador.

Com funciona Optigen?

Del teu equip al teu script en pocs passos

  1. 01

    Selecciona la plataforma

    Indica quin sistema operatiu utilitzes: Windows o Ubuntu.

  2. 02

    Defineix el teu maquinari

    Selecciona els components del teu ordinador, com el processador Intel o AMD i la targeta gràfica NVIDIA o AMD.

  3. 03

    Tria el teu perfil

    Escull el perfil que millor s'adapta al teu ús: Rendiment, Equilibrat, Neteja, Gaming o Personalitzat.

  4. 04

    Selecciona les optimitzacions

    Revisa les opcions disponibles i selecciona manualment els canvis que vols aplicar.

  5. 05

    Revisa la configuració

    Consulta el resum de les optimitzacions seleccionades abans de generar el fitxer.

  6. 06

    Genera i descarrega

    Optigen prepara un script personalitzat que podràs descarregar i executar al teu ordinador.

Compatible amb el teu sistema

Dissenyat per a Windows i Ubuntu

Optigen està pensat per treballar amb els dos sistemes operatius principals als quals s'adreça el projecte, adaptant el tipus de script generat a cada plataforma.

.ps1

Windows

  • Sistema operatiu Windows.
  • Generació de scripts PowerShell.
  • Fitxers amb extensió .ps1.
PS> .\optigen.ps1
.sh

Ubuntu

  • Sistema operatiu Ubuntu.
  • Generació de scripts Bash.
  • Fitxers amb extensió .sh.
$ bash optigen.sh

Tu decideixes què canvia al teu ordinador

Optigen no aplica canvis directament al teu sistema des del navegador. La plataforma genera un script personalitzat segons les opcions que has seleccionat, que podràs descarregar, revisar i executar localment.

01

Control total

Tu tries les optimitzacions que vols incloure.

02

Revisió prèvia

Pots consultar els canvis abans de generar el script.

03

Execució local

Els scripts es descarreguen i s'executen al teu ordinador.
