FAQ

↗
01 Què és OptiGen? + ×

OptiGen és una plataforma web que permet configurar optimitzacions del sistema. Selecciones les opcions des del navegador i OptiGen genera un script personalitzat segons les teves preferències.

02 OptiGen és una aplicació d'escriptori? + ×

No. OptiGen funciona directament des del navegador, sense necessitat d'instal·lar una aplicació d'escriptori per configurar les opcions.

03 OptiGen modifica directament el meu PC? + ×

No. OptiGen genera un script personalitzat que pots revisar abans d'executar-lo. Tu mantens el control sobre els canvis que apliques.

04 Puc revisar el script abans d'executar-lo? + ×

Sí. Pots consultar el contingut del script generat abans d'aplicar qualsevol canvi al teu equip.
